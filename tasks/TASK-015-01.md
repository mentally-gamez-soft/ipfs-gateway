# TASK-015-01: Add DATABASE_URL_PROD to .env and update settings.py

**User Story**: US-015 Production Database Setup  
**Estimated Time**: 4 hours  
**Status**: 🔄 In Progress  
**Priority**: P0 (Critical)

## Description
Add the production database connection string to the .env file and update the settings.py configuration to use the appropriate database based on the environment (development, staging, or production).

## Objectives
1. Add DATABASE_URL_PROD environment variable to .env file
2. Update BaseConfig, StagingConfig, and ProdConfig classes in settings.py
3. Ensure development environment continues using local DATABASE_URL
4. Ensure staging and production environments use DATABASE_URL_PROD
5. Add appropriate comments and documentation to configuration code

## Technical Details

### .env File Changes
Add the following line to .env:
```bash
# Production Database (Remote Server)
DATABASE_URL_PROD="postgresql+psycopg2://myuser:mypass@my-server.com:5432/ipfs_gateway"
```

### settings.py Changes
Update the configuration classes:
- Keep BaseConfig using DATABASE_URL for development
- Update StagingConfig to use DATABASE_URL_PROD
- Update ProdConfig to use DATABASE_URL_PROD
