# TASK-008-01: Structured logging config

- Story: US-008
- Estimate: 6h
- Status: Completed
- Completion: 100%
- Dependencies: TASK-001-03

## Description
Configure structured JSON logging with rotating file handler and request IDs. Ensure log levels and formats are environment-configurable.

## Acceptance Criteria
- ✅ Logs emitted in JSON with rotation.
- ✅ Request ID (correlation ID) appended to each log entry.
- ✅ Rotating file handler configured
- ✅ Log levels configurable via environment

## Implementation Details
1. Enhanced `JsonFormatter` class in `core/utils/logging.py`
   - Formats logs as JSON with timestamp, level, logger, message, module, request_id

2. Implemented `RequestIdFilter` class
   - Adds unique UUID to each request for tracing
   - Extracts request_id from Flask `g` object

3. Configured `RotatingFileHandler`
   - Writes to logs/ directory
   - Max 2MB per file, 5 backup files
   - Proper cleanup and rotation

4. `init_request_hooks()` function
   - Assigns request_id before each request
   - Logs response after each request

- `core/utils/logging.py` (enhanced)
