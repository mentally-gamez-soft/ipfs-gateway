### Connection Pool Configuration
Update `core/models/connection.py` to include production-optimized settings:

```python
def init_db(app: Flask):
    """Initialize database engine with environment-specific settings."""
    global engine
    db_url = app.config.get("DATABASE_URL")
    
    # Production-specific connection pool settings
    if app.config.get("APP_ENV") in ["staging", "production"]:
        engine = create_engine(
            db_url,
            echo=app.config.get("DEBUG", False),
            pool_size=10,                    # Base connection pool size
            max_overflow=20,                 # Additional connections under load
            pool_timeout=30,                 # Wait time for connection from pool
            pool_recycle=3600,               # Recycle connections after 1 hour
            pool_pre_ping=True,              # Verify connections before use
            connect_args={
                "connect_timeout": 10,       # Initial connection timeout
                "options": "-c statement_timeout=30000"  # Query timeout (30s)
            }
        )
    else:
        # Development uses simpler configuration
        engine = create_engine(
            db_url, 
            echo=app.config.get("DEBUG", False)
        )
    
    create_db_tables()
    logger.info(f"Database initialized: {db_url}")
```

## Performance Considerations
- **Pool Size**: Start with 10, adjust based on concurrent user load
- **Max Overflow**: Set to 2x pool size for burst traffic
- **Pool Timeout**: 30 seconds reasonable for user-facing API
- **Pool Recycle**: 1 hour prevents stale connection issues
- **Pre-ping**: Adds small overhead but prevents failed queries
