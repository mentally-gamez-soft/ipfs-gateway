## Implementation

### Tooling Selected: Flasgger
**Why Flasgger?**
- Minimal Flask integration (no additional setup)
- Auto-generates Swagger UI from YAML docstrings
- Supports OpenAPI 2.0 and 3.0
- Low overhead (single import and init call)
- Environment-aware (dev/staging only)
